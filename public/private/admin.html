How to write questions in a file Number each question, put each option on its own line starting with A, B, C…, then the answer. Instead of an Answer line you can put * after the correct option. In Word or Google Docs, type them like this and save as Web page (.html) or Plain text (.txt). 
1. Which part of the computer is its "brain"?
A. Monitor
B. CPU
C. Keyboard
D. Mouse
Answer: B

2. What does AI stand for?
A. Automatic Internet
B. Artificial Intelligence *
C. Apple Interface
For a CSV or Excel sheet use the columns: question, A, B, C, D, E, F, answer (answer is the letter).
